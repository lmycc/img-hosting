## 图片类型与使用规则

- `seeds/faces/{KEY}_face.jpg`：**面部参考**。只锁脸型、五官、发型和年龄感；不要参考背景、服装或构图。
- `seeds/body/{KEY}_body.jpg`：**体态与服装参考**。只锁体型比例、发型轮廓、服装和配饰；不要参考背景。
- `seeds/{KEY}_定妆板.jpg`：**整体设定备查**。汇总多角度体态和不同表情；多格图可能让模型平均五官或带入文字，不作为连续镜头的首选参考。
